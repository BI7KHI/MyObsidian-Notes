# 11.1 电荷 库仑定律
## 11.1.1电荷的种类和性质
* 同种电荷相互排斥，异种电荷相互吸引
* **电荷守恒定律**：在一个孤立系统中，总电量是不变的
* 基本单元：元电荷
  $$e=1.062 \times 10^{-19}C$$
* **电荷的相变论：** 系统所带电荷与参考系的选取无关，即电荷具有相对论不变性
## 11.1.2 库仑定律
### 点电荷
当带电体的大小、形状与带电体间的距离相比可以忽略时，
就可把带电体视为一个带电的几何点。
### 库伦定律 
处在静止状态的两个点电荷，在真空（空气）中的相互作用力的大小，与每个点电荷的电量成正比，与两个点电荷间距离的平方成反比，作用力的万向沿着两个点电荷的连线。
$$\mathbf{F} = k \frac{q_{1}q_{2}}{r^3} \mathbf{r}$$
$$\mathbf{F} = \frac{1}{4\pi \varepsilon_{0}} \frac{q_{1}q_{2}}{r^3} \mathbf{r}\qquad (点电荷的电场)$$
### 库仑力的叠加
对n个点电荷:
$$\mathbf{F} = \sum_{i=1}^{n} \frac{1}{4\pi \varepsilon_{0}} \frac{qq_{i}}{r_{i^3}}\mathbf{r_{i}}$$
对电荷连续分布的带电体
$$d\overrightarrow{F} = \int_{Q} \frac{q_{0}dq}{4\pi \varepsilon_{0}r^2} \overrightarrow{r_{0}}$$
# 11.2 电场和电场强度
## 11.2.1 电场与电场强度
### 电场
电场中某点的电场强度的大小等于单位电荷在该点受力的大小，其方向为正电荷在该点受力的方向。
### 电场强度
$$\mathbf{E} = \frac{\mathbf{F}}{q_{0}}$$
## 11.2.2 电场强度的叠加原理
点电荷系电场中任意一点的电场强度，等于各点电荷单独存在时该点产生的电场强度的矢量和
## 11.2.3 电场强度的计算
$$\mathbf{E} = \frac{\mathbf{F}}{q_{0}} = \sum_{i=1}^{n} \frac{1}{4\pi \varepsilon_{0}} \frac{q}{r^3}\mathbf{r_{i}}$$
## 11.2.4 电场对电荷的作用力

# 11.4 电势
## 11.4.1 静电场的环路定理
>静电力是保守力 ，静电场是保守场

$$\oint_{L'} \mathbf{E} \cdot d\mathbf{l} =0$$
上式左边是电场强度$\mathbf{E}$沿任意闭合路径L'的线积分，称为E的环流
**在静电场中，电场强度沿任意闭合路径的线积分等于0**称为静电场的环路定理

# 11.5 等势面 电势梯度
**电场中电势相等的点构成的面称为等势面**
## 11.5.2 电势梯度
电场中某一点的电场强度$\mathbf{E}$沿某一方向的分量$E_{i}$，等于电势沿该方向的导数的负值，显然，在直角坐标系中，U是坐标x,y,z的函数，电场强度$\mathbf{E}在 x, y,z$三个方向上的分量为
$$E_{x} = - \frac{\partial U}{\partial x} ，\qquad E_{y} = - \frac{\partial U}{\partial y},\qquad E_{z} = - \frac{\partial U}{\partial z } $$
电场强度$E$的矢量表达式可以写成
$$\mathbf{E} = - \left( \frac{\partial U}{\partial x}\mathbf{i} + \frac{\partial U}{\partial y}\mathbf{j} + \frac{ \partial U}{\partial z}\mathbf{k}\right)$$
数学上，把$\frac{\partial U}{\partial x}\mathbf{i} + \frac{\partial U}{\partial y}\mathbf{j} + \frac{ \partial U}{\partial z}\mathbf{k}$称为**电势梯度**，用$gradU或\nabla U$表示
$$\mathbf{E} = -gradU = -\nabla U$$
>电势梯度是一个矢量，它的大小为电势沿等势面法向的变化率，它的方向沿等势法向且指向电势增大的方向
